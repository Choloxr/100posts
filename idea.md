Build a SaaS web application that automatically generates Instagram content for businesses using AI.

The goal is NOT to create a generic AI image generator. The goal is to create a “Content Engine” that transforms products, listings, or business information into ready-to-publish Instagram posts with consistent branding.

Main target users:

* Small businesses
* Phone stores
* Car dealerships
* Real estate agencies
* Ecommerce stores
* Businesses that constantly post products/services on Instagram

Core idea:
Users should NOT need to write prompts manually. The system should feel automated and simple.

Main workflow:

1. Brand Setup (“Brand Brain”)
   The user creates their brand profile once.

Inputs:

* Brand name
* Business niche
* Website or Instagram URL
* Brand colors
* Logo upload
* Tone/style selection

  * modern
  * luxury
  * minimalist
  * bold
  * tech
  * playful
* Main goal

  * sales
  * engagement
  * leads
  * awareness

The system stores a reusable “brand identity”.

2. Market + Competitor Analysis
   The app analyzes competitors and niche content automatically.

The system should:

* Analyze Instagram-style content patterns
* Detect visual styles
* Detect popular hooks
* Detect post structures
* Extract common CTA styles
* Build a “content strategy profile”

This information should influence future generations.

3. Content Generation
   Users should generate content with minimal friction.

Examples:

* “Generate 10 posts”
* “Generate a product carousel”
* “Generate promo content”
* “Generate educational posts”

The user should never need to engineer prompts manually.

4. Product-Based Generation
   For businesses like phone stores or car dealerships:

Input:

* Product name
* Price
* Specs/features
* Optional product images

Output:

* Instagram carousel
* Post cover
* Caption
* CTA
* Story version
* Multiple variations

5. AI Architecture
   Use:

* OpenAI API for strategy, copywriting, hooks, captions, CTA generation
* fal.ai image generation APIs for visuals
* Structured prompt pipelines internally
* Consistent design generation based on stored brand identity

6. UX Philosophy
   The app must prioritize:

* simplicity
* speed
* automation
* minimal inputs
* consistent branding

The UX should feel like:
“Click button → ready-to-publish content”

NOT:
“Talk to an AI chatbot”.

7. Important Product Principles

* Consistency matters more than creativity
* Branding matters more than raw image quality
* Output must look professional and usable
* Users care about saving time and posting consistently
* The system should generate repeatable, scalable content

8. MVP Priorities
   Build only:

* Authentication
* Brand setup
* Content generation
* Post preview
* Download/export
* Simple dashboard

Avoid initially:

* complex editors
* analytics
* scheduling
* multi-platform support
* social networking features

9. Visual Direction
   Design should feel:

* modern
* premium
* minimal
* fast
* AI-native

Think:

* Framer
* Linear
* modern SaaS dashboards
* clean card layouts
* strong typography
* dark/light mode

10. Future Vision
    The long-term vision is to become:
    “An automated organic content operating system for businesses.”

Not just an AI image generator.
